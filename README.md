# Hyuckjin Choi Profile Website

Static personal profile website for GitHub Pages.

## Publish on GitHub Pages

1. Create a GitHub repository.
2. Upload the files in this folder to the repository root.
3. In GitHub, open `Settings` -> `Pages`.
4. Set `Source` to `Deploy from a branch`.
5. Select the `main` branch and `/ (root)`.
6. Save. The site will be published after GitHub finishes the Pages build.

## Files

- `index.html`: the full single-page website.
- `.nojekyll`: tells GitHub Pages to serve files as plain static assets.
